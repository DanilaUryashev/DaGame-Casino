# Slot Machine — интеграция

Система одна на все три машины (LUCK / FORTUNE / FATE) — разница только в настройках
конкретного `SlotMachineConfig` (какие символы, паттерны, веса, модификаторы).

## Что поправить под свой проект, чтобы скомпилировалось

1. **ItemSO** — весь код предполагает, что твой класс предмета называется `ItemSO`.
   Если у тебя он называется иначе — переименуй свой класс или сделай find-replace
   `ItemSO` → твоё реальное имя во всех файлах (используется в SlotSymbol.cs и ItemInstance.cs).

2. **ISlotSpinner** — реализуй этот интерфейс на своём PlayerController
   (`TrySpendCurrency`, `ApplyDamage`, `Kill`). Без этого машина не сможет
   списывать валюту и наносить урон/убивать.

## Точки интеграции (помечены TODO прямо в коде)

3. **Спавн предмета в мире** — `SlotMachineController.PerformSpin()`, ветка `else`
   (когда результат не смерть) — нужно вызвать твой существующий метод дропа
   предмета на землю рядом с машиной (предметы падают на землю, не в инвентарь напрямую).

4. **Вайп команды** — там же, при `isTeamWipe` — сейчас вызывается `spinner.Kill()`
   только для того, кто крутил. Если вайп должен убивать всю команду — подключи
   свой менеджер сессии/пати вместо этого вызова.

5. **UI результата** — `SlotMachineVisual.BuildResultRow()` создаёт пустую строку
   из `resultRowPrefab`, но ничего в неё не пишет — раскладку строки (иконка + текст
   бафа) нужно сделать под свой конкретный префаб.

6. **BoostPatternWeight чарма** — в `CharmApplier.cs` реализован упрощённо (общий
   буст всех не-мусорных символов), не точечный буст одного паттерна/тира. Если
   понадобится точнее — можно разобрать отдельно.

## Что настроить в сцене и ассетах

- На каждую машину — свой `SlotMachineConfig` (Create → SlotMachine → Machine Config).
- Символы — по одному ассету `SlotSymbol` на каждый визуальный символ барабана.
  Не забудь одинаковый `symbolId` у ВСЕХ мусорных ячеек и одинаковый — у всех
  черепов (см. комментарий в SlotSymbol.cs, по умолчанию -1 и -2).
- Паттерны прописываются прямо в инспекторе `SlotMachineConfig` (список Patterns) —
  координаты ячеек руками, один раз на весь проект.
- `SlotMachineVisual` — для каждой из 5 колонок нужен `RectMask2D` (или `Mask`)
  с фиксированной высотой на 3 ячейки, и внутри — длинная лента (`strip`) из Image,
  штук 15-20 на колонку (см. комментарии в `SpinSingleColumn`).

## Что это сознательно НЕ делает

- Не решает баланс — все веса, стоимость спина, урон от черепа (10 / 25 в
  RewardResolver.BuildSkullResult) — заглушки-числа, подбираешь сам через плейтест.
- Не рисует сами иконки/спрайты — только логику, куда их подставить.

## Порядок сборки (если будешь проверять по шагам, а не всё разом)

1. SlotSymbol + SlotMachineConfig — создать ассеты, проверить что видно в инспекторе.
2. GridGenerator — вызвать вручную, вывести сетку в консоль, проверить что веса работают.
3. PaylinePattern + RewardResolver — зафорсить сетку руками под конкретный паттерн,
   проверить что совпадение находится верно.
4. Модификаторы — проверить что один и тот же символ в разных спинах получает разные бафы.
5. Черепа — добавить и проверить что не ломает уже работающую логику оружия.
6. CharmApplier — проверить что веса меняются только на один спин.
7. SlotMachineVisual — анимация в последнюю очередь, когда логика уже проверена в консоли.

## Добавлено вторым заходом: генератор паттернов + тест без UI

- **PatternPresets.cs** — статические методы, которые сами считают координаты типовых
  паттернов (линии, V-вниз/вверх, X, углы, периметр, крест, ромб, джекпот) под любой
  размер сетки, вместо ручного набора Vector2Int. Диагонали на не квадратной сетке (5x3)
  посчитаны как V-образный маршрут — так задаются линии выплат в настоящих слотах,
  когда столбцов больше чем строк.
- **SlotMachine/Editor/SlotMachineConfigEditor.cs** — кастомный инспектор для
  SlotMachineConfig с кнопкой "Заполнить стандартными паттернами". ВАЖНО: файл должен
  лежать именно в папке с именем `Editor` — так требует Unity. Если в проекте уже есть
  своя папка Editor — просто перенеси файл туда, главное не оставлять его вне такой
  папки, иначе будет ошибка компиляции в билде.
- **SlotMachineDebugTester.cs** — повесь на любой объект в сцене вместе с готовым
  SlotMachineController, назначь ссылку, и в Play Mode через правый клик на компонент
  в инспекторе -> "Test Spin". В консоли распечатается сетка и результаты спина текстом —
  это и есть шаги 2-4 выше, просто готовым инструментом вместо ручных Debug.Log.

Кнопка генератора паттернов создаёт паттерны с пустыми пулами модификаторов (кроме
самих линий, которым баф и не нужен) — зайди в инспектор конфига после генерации
и назначь ModifierType-ассеты туда, где они нужны (диагонали/углы/ромб/крест/периметр/X).
